# Woo Themes — deprecated

> [!WARNING]
> This repository is deprecated. Purple development is moving to the [WooCommerce monorepo](https://github.com/woocommerce/woocommerce) under `themes/purple/`.

Please submit new issues and pull requests to [woocommerce/woocommerce](https://github.com/woocommerce/woocommerce). For theme bugs and feedback, use the [Theme feedback or bug report template](https://github.com/woocommerce/woocommerce/issues/new?template=theme-feedback.yml) and include Purple’s name and version.

This repository preserves the original WooCommerce starter theme source and history for reference.

Purple itself is not deprecated. Follow the theme's documentation in the WooCommerce monorepo for installation, development, and release instructions once the migration is merged.
