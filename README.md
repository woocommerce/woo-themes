# Woo Themes — deprecated

> [!WARNING]
> This repository is deprecated. Purple development is moving to the [WooCommerce monorepo](https://github.com/woocommerce/woocommerce) under `themes/purple/`.

Please submit new issues and pull requests to [woocommerce/woocommerce](https://github.com/woocommerce/woocommerce). For bug reports and feedback, use its [issue chooser](https://github.com/woocommerce/woocommerce/issues/new/choose) and mention Purple.

This repository preserves the original WooCommerce starter theme source and history for reference. Release preparation and publishing workflows have been removed; future development and releases will be managed in the WooCommerce monorepo after the migration lands.

Purple itself is not deprecated. Follow the theme's documentation in the WooCommerce monorepo for installation, development, and release instructions once the migration is merged.
