# Agent instructions

## Pull request descriptions

When creating pull requests, always use the template from `.github/PULL_REQUEST_TEMPLATE.md`. Its key sections are:

- **Changes proposed in this Pull Request**: Describe the changes and why they are needed.
- **Screenshots or screen recordings**: Include before-and-after visuals for UI changes; remove this section when it does not apply.
- **How to test the changes in this Pull Request**: Include detailed, reproducible testing instructions.

Remove any template sections that do not apply and replace all placeholders.
